Potasko

Your little task potato, a CalDAV todo app.

A simple task manager that syncs with CalDAV servers.

Download latest release 📦

Built for Linux and Android.

🥔 Fork this potato on GitHub

Task Management

  • Task completion tracking
  • Due dates and priorities
  • Recurring tasks (RRULE)
  • Multiple task lists

CalDAV Sync

  • Works with Nextcloud, Radicale, Baikal
  • Automatic conflict resolution
  • Eager sync on changes
  • Background synchronization

Offline-First

  • Local SQLite storage
  • Work without internet
  • Sync when connected
  • Change queue with retry

Built With

Tauri 2.0 Rust SvelteKit SQLite CalDAV
